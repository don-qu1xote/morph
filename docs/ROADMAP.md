# Что дальше

- Синхронизировать лайки периодически, а не только при запуске.
- Сборка под Windows в CI: сейчас Windows собирается только скриптом upstream.
- Выравнивать громкость: треки с YouTube и SoundCloud в смешанной волне
  звучат то тише, то громче яндексовских.
- Плавный переход между треками. Сейчас следующий стартует с диска сразу,
  но без кроссфейда: для него нужен второй плеер.
- Скробблинг в Last.fm, чтобы статистика по всем трём сервисам копилась в
  одном месте.
- Список, который играет, хранить отдельно от того, что открыто на экране:
  сейчас «дальше» после смены экрана берёт треки из нового списка.
- VK Музыка как ещё один источник для MAIN. Официального API для музыки у VK
  нет, а токены сторонних клиентов вроде Kate Mobile с сентября 2026 упираются
  в лимиты. Вернуться, если появится устойчивый способ, иначе только импорт
  списка треков из VK.
- Холодный старт модели из истории Яндекса (`/music-history`): сейчас профиль
  вкуса до первых прослушиваний в morph строится только по лайкам.
- Пересчитывать свои плейлисты в фоне раз в день, а не только при запуске.
- Звуковые признаки в модель (темп, громкость, энергия), чтобы волна держала
  настроение, а не только артистов.
- Сервер для телефона: ядро morph за API Subsonic, чтобы слушать то же самое
  с айфона в Subsonic-клиенте.
- Предложить upstream то, что не завязано на форк: совместимость с Qt 6.4,
  номер сборки из git, исправленную статистику прослушиваний, очередь.
