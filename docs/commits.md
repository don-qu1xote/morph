# Коммиты

```
[MORPH-AREA-NN] описание
```

| Часть | Что это |
|---|---|
| `AREA` | область, таблица ниже |
| `NN` | номер внутри области, две цифры |
| описание | что стало иначе, по-русски, до 72 символов |

Фикс к уже влитому коммиту: `[MORPH-AREA-NN fix]`, второй `fix2` и дальше.

| AREA | Область |
|---|---|
| `INF` | правила кода, хуки, Makefile |
| `BUILD` | CMake, структура сборки |
| `MAC` | всё, что только про macOS |
| `ARCH` | устройство ядра без изменения поведения |
| `SYNC` | что уходит в аккаунт: статистика, волна, лайки, слияния с upstream |
| `FB` | фолбэки для треков, которых нет в Яндексе |
| `UI` | QML-темы |
| `CI` | Docker, GitHub Actions |
| `DOC` | документация |

Примеры:

```
[MORPH-SYNC-02] Моя волна через rotor-сессии: старт, скип, дослушал уходят в Яндекс
[MORPH-FB-02] SoundCloud вторым фолбэком, если на YouTube трека нет
```
