# ADR-0014: Плейлисты, которые собирает morph

## Статус

Принято.

## Контекст

Персональные плейлисты Яндекса (Плейлист дня, Дежавю, Тайник) знают только
Яндекс. Миксы SoundCloud знают только SoundCloud. Ни те ни другие не видят
лайков и прослушиваний с остальных площадок и убранных из каталога треков.

## Решение

`MorphMixes` собирает свои плейлисты из MAIN и истории прослушиваний. Они
стоят первыми в ряду For You, карточка ведёт на адрес вида `morph:onrepeat`,
и по клику его открывает тот же `importPlaylist`, что и плейлисты сервисов.

| Плейлист | Что в нём |
|---|---|
| Daily Mix 1-4 | группа артистов, которых слушаешь вместе, плюс похожее новое (треть) |
| Discover Weekly | незнакомые артисты рядом с любимым, по треку на артиста, обновляется по понедельникам |
| Release Radar | альбомы и синглы любимых артистов за последние 45 дней, новые первыми |
| On Repeat | заслушанное за месяц: дослушал +1, недослушал +0.3, скип -0.5 |
| Rediscover | лайки, которые не звучали два месяца, порядок меняется раз в неделю |

**Группы для Daily Mix.** Артисты связаны, если дослушаны в одной сессии
(без перерыва в полчаса) или лайкнуты рядом: в окне из восьми лайков подряд,
с половинным весом. Вес связи делится на размер группы, чтобы день музыки
без перерыва не сделал соседями всех. Дальше распространение меток (label
propagation): каждый артист берёт метку, у которой больше всего общего с ним
веса, свою метку он держит с небольшой форой. Обход и выбор при равенстве
идут по порядку любви, поэтому группы не меняются от запуска к запуску.
Берутся четыре самые любимые группы от двух артистов.

**Похожее новое** даёт Яндекс (`/tracks/{id}/similar`) по трём песням группы
и SoundCloud (related) по одной. Всё вместе ранжирует та же модель, что и
волну ([ADR-0013](0013-own-ranking-over-services.md)), без разведки и с
долей нового 0.35.

## Последствия

- Карточки считаются на месте за миллисекунды, запросы уходят только по
  клику на Daily Mix, Discover Weekly и Release Radar.
- Без истории Daily Mix собираются по лайкам. Чем больше слушаешь в morph,
  тем точнее группы.
- Discover Weekly хранится в `discover.json` до понедельника, как у
  Spotify: список недели не меняется от каждого клика.
