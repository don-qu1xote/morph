# ADR-0004: Лайки, источник правды на стороне сервиса

## Статус

Принято.

## Контекст

В upstream лайки жили только в локальном `settings.json`: лайк в morph не
попадал в аккаунт, а лайки с телефона не появлялись в morph. Рекомендации о
них ничего не знали.

## Решение

- Лайк и снятие лайка в morph сразу уходят в аккаунт.
- При запуске и смене токена morph забирает все лайки аккаунта и сливает с
  локальными.
  Для треков этого сервиса правда на стороне сервиса: появившиеся добавляются
  наверх, снятые удаляются. Лайки YouTube и SoundCloud не трогаются.
- Если сервис вернул id лайка, но не отдал по нему данных (трек убран из
  каталога), локальная запись остаётся. Иначе пропадали бы как раз удалённые
  треки, ради которых всё и затевалось.
- Если не пришла хотя бы одна пачка данных, слияния нет вообще.

## Последствия

- Лайк из morph сразу виден на телефоне, а лайкнутое на телефоне появляется в
  morph при следующем запуске.
- Лайк, который не дошёл до сервера из-за сети, при следующей синхронизации
  исчезнет локально. Это честнее, чем расхождение, которое никто не заметит.
