# ADR-0001: Форматировать только изменённые строки

## Статус

Принято.

## Контекст

Upstream не пользуется clang-format. `.clang-format` форка подогнан под то,
как код уже написан (4 пробела, указатель у типа, короткие `if` в одну
строку), но даже так прогон по всему upstream поменял бы 477 строк из 4424:
в основном длинные строки и переносы.

Такой коммит не несёт смысла, но делает каждое следующее слияние с upstream
конфликтом почти в каждом файле.

## Решение

Форматом и clang-tidy проверяются только строки, которые форк поменял
относительно коммита upstream из `.upstream`:

- `make fmt` и `make fmt-check` работают через `git clang-format <upstream>`;
- pre-commit смотрит только то, что лежит в индексе;
- `make tidy` гоняет `clang-tidy-diff` по изменённым строкам.

## Последствия

- Свой код всегда по правилам, чужой не трогается, слияния с upstream
  остаются дешёвыми.
- После слияния с upstream `.upstream` надо обновить, иначе изменения
  upstream будут считаться своими (описано в DEVELOPMENT.md).
- Если upstream когда-нибудь заведёт свой формат, ADR пересматривается.
