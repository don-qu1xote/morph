# ADR-0011: Тексты песен из Яндекса и LRCLIB

## Статус

Принято.

## Контекст

Синхронный текст (строка подсвечивается по ходу трека) есть у Яндекса, но
только для его треков и только тех, что ещё в каталоге. Убранные треки
играют с YouTube и SoundCloud, а у этих сервисов синхронных текстов нет.

## Решение

`LyricsService` ищет текст так:

1. Трек из Яндекса: `GET /tracks/{id}/lyrics?format=LRC`. Запрос подписан
   HMAC-SHA256 от id трека и времени ключом из Android-приложения, как в
   yandex-music-api. В ответе ссылка на файл LRC.
2. Если Яндекс не дал текст или трек не из Яндекса: открытая база LRCLIB,
   сначала точный запрос по первому артисту, названию и длительности, потом
   обычный поиск.

LRC разбирается в C++ (`LyricsService::parseLrc`): несколько меток у одной
строки, теги вроде `[ar:]` пропускаются, текст без меток идёт как обычный.
Найденное хранится в памяти до перезапуска.

## Последствия

- Убранные из Яндекса треки тоже получают синхронный текст, если он есть в
  LRCLIB, а там много русского рэпа.
- В LRCLIB уходят артист, название и длительность трека, больше ничего.
  Ключей и регистрации у неё нет.
- Если Яндекс сменит ключ подписи, тексты его треков пойдут из LRCLIB, а не
  пропадут.
