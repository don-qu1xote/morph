# ADR-0017: Обложки плейлистов с доски Pinterest

## Статус

Принято.

## Контекст

У своих миксов morph обложкой служит обложка первого трека, у плейлистов,
которые ты собираешь сам, её часто нет вовсе. Хотелось, чтобы у каждого
плейлиста была картинка в твоём вкусе и каждый раз новая.

Публичный поиск пинов по слову в Pinterest API v5 есть только у партнёров.
Обычному приложению с trial-доступом API отдаёт только свои доски и пины.

## Решение

`PinterestCovers` берёт картинки с одной твоей доски:

- в настройках токен (Pinterest Token, хранится зашифрованным, как токены
  Яндекса и SoundCloud) и доска (Pinterest Board): ссылка, имя или id;
- доска находится среди твоих (`GET /v5/boards`) по имени, без разницы между
  регистром, дефисами и подчёркиваниями; id идёт сразу в
  `GET /v5/boards/{id}/pins`, страницами до 500 картинок;
- у пина берётся нарезка 1200x, если её нет, то поменьше, оригинал никогда:
  он бывает в десятки мегабайт;
- каждая выдача это картинка, которой ещё не было ни у одного плейлиста. Когда
  доска кончается, начинается новый круг, но не с той картинкой, что у
  плейлиста сейчас. Выданное лежит в `pinterest.json`.

Новую картинку получают: карточки своих миксов при каждом показе главной;
твои плейлисты без обложки или с обложкой с доски при каждом запуске;
открытый плейлист по кнопке NEW COVER. Обложку, поставленную руками
ссылкой, morph не трогает.

## Последствия

- Нужен токен из кабинета разработчика Pinterest (developers.pinterest.com):
  приложение с trial-доступом и токен с правами `boards:read` и `pins:read`.
  Тестовый токен из песочницы живёт 30 дней, его адрес API подменяется через
  `MORPH_PINTEREST_API`.
- Подобрать картинку под настроение плейлиста по слову нельзя, пока Pinterest
  не откроет поиск. Настроение задаёт то, что ты сам собрал на доске.
