# ADR-0012: MAIN, одна библиотека на все площадки

## Статус

Принято.

## Контекст

Лайки в morph лежат одним списком, но каждая версия песни там отдельная
запись: лайкнул трек в Яндексе и его же на SoundCloud, получил два трека
подряд. Трек с SoundCloud играл только с SoundCloud: удалили его там, и
песни нет, хотя в Яндексе она есть. А Яндекс ничего не знал о том, что
слушается и лайкается на других площадках, и его рекомендации этого не
учитывали.

## Решение

`Library` (в QML `MorphLibrary`) собирает MAIN из лайков всех сервисов.
Одна песня это одна запись, ключ `TrackMatch::songKey`: первый артист,
название без скобок и пометки версии вроде remix или live, чтобы ремикс не
слился с оригиналом.

- **Состав берётся из лайков.** Своего списка песен у `Library` нет, поэтому
  разъехаться с лайками она не может. Снятый лайк снимается со всех версий
  песни сразу, иначе оставшаяся версия вернула бы её в MAIN.
- **Что показывать.** Из лайкнутых версий та, что играет надёжнее: Яндекс,
  если он трек отдаёт, потом SoundCloud, потом YouTube. Остальные площадки
  видны значками рядом.
- **Связи.** Для песен без версии в Яндексе morph в фоне ищет её там, по одной
  с паузой в полторы секунды и не больше 40 за запуск. Берётся только
  совпадение от 0.85 по `TrackMatch::score`. Не нашлось, повтор через неделю.
  Связи лежат в `library.json` и переживают снятый лайк.
- **Фолбэк.** Известные версии песни пробуются раньше поиска: убранный из
  Яндекса трек играет лайкнутой версией с SoundCloud, удалённый с SoundCloud
  играет из Яндекса. Поток по-прежнему приходит под исходным id
  ([ADR-0005](0005-fallback-under-original-id.md)).
- **Синхронизация с Яндексом** включается в настройках (Sync to Yandex) и по
  умолчанию выключена: она меняет коллекцию в аккаунте. Включена, и лайк,
  снятый лайк и прослушивание трека с SoundCloud или YouTube уходят и
  связанной версии в Яндексе.

## Последствия

- В MAIN нет повторов, и любая песня играет, пока она есть хоть на одной
  площадке.
- С синхронизацией Моя волна учится и на том, что слушается вне Яндекса.
  Цена: лишние запросы поиска в Яндекс при первом запуске с большой
  коллекцией на SoundCloud.
- Песня без названия (такое бывает у старых загрузок) остаётся отдельной
  записью и не связывается.
