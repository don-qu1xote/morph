# ADR-0006: Docker только как среда сборки

## Статус

Принято.

## Контекст

morph это десктопный плеер. Из контейнера на macOS нельзя нормально вывести
окно и звук, так что запускать приложение в Docker бессмысленно. При этом
сборка зависит от версий Qt, clang-format и clang-tidy, и «у меня собирается»
легко расходится с CI.

## Решение

`docker/Dockerfile` описывает среду сборки на Ubuntu 24.04: Qt 6, clang-tidy
и clang-format 18.1.8. `make docker-ci` прогоняет в ней формат, сборку, тесты
и tidy. Linux-джоба CI делает ровно то же самое. macOS собирается нативно на
раннере GitHub и выкладывает `morph.dmg`.

## Последствия

- Красный CI воспроизводится локально одной командой.
- Linux-сборка идёт на Qt 6.4 из Ubuntu, поэтому код держится совместимым с
  6.4, хотя на маке Qt свежий.
- docker compose не нужен: сервисов нет, есть одна среда.
