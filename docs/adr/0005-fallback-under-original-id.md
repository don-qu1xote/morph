# ADR-0005: Фолбэк под исходным id трека

## Статус

Принято.

## Контекст

Треки пропадают из каталога Яндекса (истекла лицензия, требование
правообладателя или госорганов), а в лайках, плейлистах и волне остаются их
id. На YouTube и SoundCloud эти песни обычно есть.

## Решение

Если Яндекс не отдаёт поток (ошибка 4xx/5xx от сервера, пустой
`download-info` или `available: false`), трек ищется по «артист - название»:
сначала через yt-dlp на YouTube, потом на SoundCloud. Найденный поток
приходит в `streamUrlReady` под исходным яндексовским id.

Отсутствие сети это не повод для поиска: тогда показывается ошибка сети.

## Последствия

- QML, кэш, история и плейлисты ничего не знают о подмене: трек просто
  играет, а после первого раза лежит в кэше и играет офлайн.
- Поиск по названию может найти не ту версию (live, кавер). Для редких
  треков это лучше, чем тишина.
- Тот же механизм работает для импорта `.txt`: строка превращается в трек с
  id `ytq-<base64 запроса>`, который ищется в момент запуска.
